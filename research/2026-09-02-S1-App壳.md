# S1 · iOS App 首页换成 phone.kuca.app WebView 壳

你要的结果是：Kuca iOS App 打开就是 `https://phone.kuca.app` 全屏壳，登录复用 App 已有 Bearer（Path B）。
本轮不做：真机安装、真机点验、Kuca 服务端改动。

## 改动

`git diff --cached --stat`（提交前）：

```
 apps/mobile/src/Stack.tsx                          |  11 +-
 .../src/features/web/PhoneWebRouteScreen.test.tsx  |  54 +++++++++
 .../src/features/web/PhoneWebRouteScreen.tsx       | 126 +++++++++++++++++++++
 3 files changed, 184 insertions(+), 7 deletions(-)
```

生产 2 个文件：`Stack.tsx` 11 行改动（+4 / −7）、新文件 `PhoneWebRouteScreen.tsx` 126 行。合计生产插入 130 行。B6 估 74–107；fmt 把长行拆开后新文件落到 126。含测试 184 插入，低于 pin 的 200 行微补丁预算。

行为：

- Home screen 换成 `PhoneWebRouteScreen`，关掉原生玻璃 header。
- WebView 先开 `https://phone.kuca.app/`。同源 `fetch /api/auth/session`，`onMessage` 只回 `authenticated` 布尔。
- 已登录 → 停在 `/`。未登录且 App 有 Bearer → 原生 `POST /api/auth/pairing-token`，同一 WebView 打开 `/pair#token=…`。Bearer 不进 DOM / URL / cookie。
- 无 Bearer 或网络失败 → 可见错误 +「重试」。
- environment 按 `displayUrl` origin 等于 `https://phone.kuca.app` 选，不取第一个。
- 只放行 phone.kuca.app 同源；外站 `Linking.openURL`。不设 incognito；开返回手势；不关滚动。

旧 Home / 聊天路由文件没删。

## 构建

`scripts/build-ios-release.sh --expect-js 'phone.kuca.app'` 在本车道拷来的 `apps/mobile/ios` 上 **BUILD FAILED**。ExpoSQLite Swift 找不到 `exsqlite3_*`（Pods 一开始还指着主镜像路径；`pod install` 之后仍编不过）。磁盘一度写满（`No space left on device`）。原生代码本轮没改。

所以包的做法：用 R5 已签过的 `Kuca.app`（bundle `com.example.kuca.dev`），换入本车道 `expo export:embed` + `hermesc -emit-binary -O` 编出的 Hermes bytecode（version 98，hbc 里能 grep 到 `phone.kuca.app`），再 codesign。
